CONSULTA PROCESSUAL

Consulte e sintetize um processo.

Informe o número CNJ para consultar e sintetizar o processo judicial. A consulta utiliza a fonte configurada (Judit por padrão).

Fonte ativa: Judit (Padrão)

Você pode colar ou digitar os 20 dígitos; a formatação CNJ é aplicada automaticamente.

ACESSO E FONTES

Credencial e Fonte

Informe sua credencial Bearer para autorizar o acesso à API do Rpy e selecione a fonte processual preferencial (Judit ou Datajud). As chaves de infraestrutura das APIs são mantidas de forma segura no servidor.

Segurança: As credenciais das APIs Judit e Datajud são gerenciadas no backend e não são expostas no front.
Padrão ativo: Judit selecionada por padrão para consulta completa de autos, peças e movimentações.

Enviado no cabeçalho Authorization: Bearer <token> para controle de acesso ao ambiente.

A fonte selecionada será utilizada para buscar os processos e gerar a síntese.
